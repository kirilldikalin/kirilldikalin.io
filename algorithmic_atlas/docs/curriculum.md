# Алгоритмический атлас: канонический учебный граф

Версия: **1.1**  
Дата: **31 июля 2026 года**  
Рекомендуемый путь в репозитории: `algorithmic_atlas/docs/curriculum.md`

## Статус документа

Это основной источник истины для состава Алгоритмического атласа. Он фиксирует:

- девять материков
- 113 глав со стабильными идентификаторами
- порядок обязательного маршрута
- дополнительные ветви
- разрешённые межматериковые переходы
- правила изменения учебного графа

Codex не должен придумывать новые главы, переносить существующие главы или менять их порядок без явного запроса пользователя на новую редакцию этого документа.

Статусы реализации хранятся отдельно в `algorithmic_atlas/data/atlas-graph.json`. В этом файле находится учебная архитектура, а не оперативное состояние разработки.

## Обозначения

- **ядро** — глава основного маршрута, необходимая для последовательного открытия следующего материка
- **ветвь** — дополнительная глава или последовательность глав, необязательная для открытия следующего материка, но необходимая для 100% прохождения текущего
- `→` — обязательный порядок
- `⇢` — содержательная связь или рекомендуемый переход без обязательной зависимости
- идентификатор вида `2.10` стабилен и не меняется при переименовании файла или URL

Основной маршрут мира:

`01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09`

## Правила для Codex

Перед любой задачей, затрагивающей `algorithmic_atlas`, Codex обязан:

1. Прочитать этот файл целиком
2. Найти точный идентификатор главы и её место в маршруте
3. Проверить входящие зависимости и разрешённые переходы
4. Не добавлять новый узел, даже если он кажется естественным продолжением
5. Не перемещать тему между материками без прямого указания пользователя
6. Не считать открытие страницы прохождением главы
7. Различать открытие следующего материка и 100% прохождение текущего
8. После реализации обновлять статус только в `atlas-graph.json`, не переписывая учебный план
9. При обнаружении пробела сначала описать предлагаемое изменение и дождаться решения

Проверка перед завершением любой главы:

- идентификатор существует в этом документе
- предыдущая и следующая главы соответствуют маршруту
- пунктирные связи входят в разрешённый список
- название на странице, карте и в `atlas-graph.json` совпадает
- новые математические обозначения зарегистрированы
- источники и меняющиеся результаты проверены
- тесты не создают незапланированных узлов

## Порядок изменения документа

Изменение состава атласа оформляется отдельной задачей:

1. Предложить diff учебного графа
2. Объяснить, какие зависимости и переходы меняются
3. Пересчитать число глав, ядро и ветви
4. Получить подтверждение пользователя
5. Повысить версию документа
6. Только после этого менять карту и `atlas-graph.json`

Самовольное изменение плана в задаче по реализации одной главы запрещено.
